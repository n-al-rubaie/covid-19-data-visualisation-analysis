## COVID-19 Data Visualisation Analysis

This project presents a comprehensive data visualisation analysis of global and European **COVID-19 trends**, using both **Python-based visualisations** and a **Tableau dashboard**.

Through a series of visualisations, the analysis explores:

- Vaccination coverage  
- Vaccine diversity  
- Infection rates  
- Mortality comparisons across different regions and countries  

The project integrates data from **WHO COVID-19 global statistics** and **vaccination datasets**, ensuring reliability and relevance. In addition, the **Tableau dashboard** provides an interactive overview that enhances data exploration and enables meaningful comparisons between regions.

Overall, this project demonstrates the effective use of multiple visualisation tools to clearly communicate complex public health data in an accessible and visually engaging manner.
